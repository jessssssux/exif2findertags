#### v0.3.0

> 4 October 2026

- Replaced `setup.py` with `pyproject.toml`. The package needs Python 3.10 or later and installs on Python 3.10 to 3.14.
- Updated the dependencies: PyObjC 11 or later (was below 10), textX 4 (textX 3 imports `pkg_resources`, which setuptools 81 removed), cloup 4, rich 13 or later, pathvalidate 3, yaspin 3 and osxmetadata 1.4.1. Removed the unused AVFoundation and Metal PyObjC frameworks.
- Fixed `--help` and `--xattr-template rating`. Both failed with `KeyError: 'rating'` because osxmetadata renamed the attribute to `starrating`. `rating` now writes `kMDItemStarRating` as a number.
- Fixed `--xattr-template` for `description`, `headline`, `keywords` and `title`. The tool reported that it wrote these attributes, but `MDItemSetAttribute` ignored them and nothing was stored. The tool now writes every attribute directly to its `com.apple.metadata` extended attribute.
- Fixed Finder comments and `--xattr-template` on files that Spotlight did not index. The tool read existing values from the Spotlight index, so it saw no value and replaced an existing Finder comment instead of appending to it. The tool now reads the values from the file.
- Fixed the 10 tests that failed on Ventura and later (#15). Added tests for the attributes above, for appending to an existing Finder comment and for `--help`.
